# Зарлагын дэвтэр

Python ашиглан хийсэн зарлага бүртгэх жижиг төсөл.

## Төслийн зорилго

Өдөр тутмын зарлагыг ангилал, барааны нэр, үнийн хамт файлд хадгалж, дараа нь нийт дүн болон ангилал тус бүрийн дүнг харах боломжтой болгох.

## Боломжууд

- Зарлага нэмэх
- Зарлага харах
- Нийт дүн харах
- Ангилал тус бүрийн нийт харах
- Хамгийн их зарлага харах
- Бүх зарлага цэвэрлэх
- Нийт зарлагын тоо харах
- Программаас гарах

## Ашигласан Python ойлголтууд

- Function
- Return
- List
- Dictionary
- File handling
- `with open()`
- `r`, `a`, `w`
- `while`
- `for`
- `if / elif / else`
- `split()`
- `strip()`
- `append()`
- `len()`
- `max()`
- `int()`
- `break`
- `continue`
